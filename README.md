# Python Quest

Бесплатный веб-тренажёр Python для будущих аналитиков и ML-специалистов. Перед каждым уровнем идёт урок с живыми примерами, после него — задачи, которые проверяются прямо в браузере на скрытых тестах. Вторая игра серии Quest после [SQL Quest](https://hpainh.github.io/sql-quest/).

**Играть:** https://hpainh.github.io/python-quest/

Задачи решаются на датасете ShopData — вымышленном интернет-магазине из SQL Quest: каталог, клиенты, заказы, «грязные» выгрузки, события продукта, A/B-эксперименты, отток клиентов и спрос по дням. Все таблицы открыты на экране «Данные».

## Как устроена игра

- **Урок перед уровнем.** Задачи открываются, когда прочитаны все разделы и самопроверка сдана минимум на 80%. Если тема уже знакома, можно сдать экспресс-тест: 6 из 6 верных ответов.
- **Двенадцать типов задач:** программа с вводом и выводом, функция, исправление бага, «что выведет код», заполнение пропусков, а для библиотек — массив, таблица, значение, «без циклов» (векторизация с лимитом времени), график, статистика и модель. Последняя задача уровня — босс.
- **Проверка по результату.** Код сначала разбирается статически, потом прогоняется на видимых тестах, потом на скрытых, включая 20–40 случайных. Задачи библиотек запускаются ещё на скрытом наборе данных другого размера, с новыми городами и категориями. График сравнивается по данным, а не по способу построения; статистика — с допуском; модель обучается на открытых данных и оценивается метрикой на скрытых, плюс проверки на утечку и на перемешанную цель. Захардкоженный ответ не проходит.
- **Пять подсказок на задачу:** направление со ссылкой на раздел урока, алгоритм словами, нужные функции, каркас, решение с разбором. Каждая подсказка снижает XP.
- **Детекторы ошибок.** 120+ правил по AST, типу исключения и разнице вывода объясняют ошибку по-русски: `int(input())` для двух чисел, `print` вместо `return`, `/` вместо `//`, лишний текст в `input()`, бесконечный цикл, `and` вместо `&` в маске pandas, забытые скобки в условиях, цепочное присваивание, inner вместо left в merge, размножение строк из-за дубликатов ключа, перепутанная ось, односторонний тест вместо двустороннего, утечка при fit до разбиения, некодированные категории, переобучение и так далее.
- **Прогресс без сервера.** Прогресс хранится в браузере. Код сохранения `PQ1-…` с контрольной суммой переносит его на другое устройство. Пароль уровня, который выдаётся за босса, открывает следующий уровень.

## Запуск у себя

Нужен Node.js 22+. При первой сборке скрипт скачивает Pyodide с GitHub (архив около 340 МБ) и распаковывает в `vendor/pyodide` только ядро и нужные пакеты — NumPy, pandas, matplotlib, SciPy, statsmodels, scikit-learn и их зависимости; seaborn лежит в `extra-wheels/`. Папка не попадает в git, на GitHub Actions она кэшируется.

```bash
npm ci
npm run fetch:pyodide # скачать Pyodide (один раз)
npm run dev          # собрать контент и запустить на http://localhost:5173
npm test             # юнит-тесты и негативные сценарии
npm run build        # собрать сайт в dist/
npm run e2e          # сквозной тест в Chromium по собранному сайту
```

## Публикация на GitHub Pages

В Windows PowerShell из папки проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\publish.ps1
```

Скрипт:
1. проверяет git, Node.js и GitHub CLI;
2. скачивает Pyodide при первом запуске, прогоняет сборку и тесты;
3. создаёт публичный репозиторий `python-quest`;
4. включает Pages через GitHub Actions и ждёт публикации.

Дальше каждый push в `main` пересобирает сайт.

## Как добавить задачу

Задача — YAML-файл в `content/<трек>/<уровень>/tasks/`. Сборка `npm run build:content` выполняет эталон в Pyodide и падает, если:
- эталон не проходит свои тесты;
- подсказок не ровно 5;
- вариант с багом проходит проверку или не вызывает ожидаемый детектор;
- у задачи нет ссылки на раздел урока.

```yaml
id: C2-01-count-up
type: stdio              # stdio | function | fix_bug | predict | fill_gaps | array | dataframe | value | vectorize | plot | stat | model
title: От 1 до n
difficulty: 1            # 3 = задача со звёздочкой
lesson_section: for-range
statement: |
  Дано натуральное число n. Выведи числа от 1 до n.
reference: |
  n = int(input())
  for i in range(1, n + 1):
      print(i)
tests:
  visible: ["3", "1"]    # ожидаемый вывод считается по эталону
  hidden: ["2", "57"]
random: {count: 10, gen: "str(random.randint(1, 200))"}
requires: ["uses:for"]
star3: [first_try]
buggy_variants:
  - code: "n = int(input())\nfor i in range(1, n):\n    print(i)"
    expect_detector: range_bounds
hints: ["...", "...", "...", "...", "..."]
```

Новые задачи автоматически получают слот в `content/slots.json`. Слоты только добавляются и никогда не переставляются, иначе старые коды сохранения прочитаются неверно.

## Стек

React + Vite, CodeMirror 6, Pyodide 314 (CPython 3.14 в WebAssembly) в Web Worker, Vitest, Playwright. Pyodide и пакеты лежат на самом сайте (`/pyodide/`) и грузятся по требованию: ядро — при первом запуске кода, библиотеки — при первом уровне, где они нужны (scikit-learn — около 10 МБ). Браузер кэширует их после первой загрузки.
