# Индексация и маски

## Зачем это нужно {#why}

Аналитик постоянно выбирает часть данных: продажи за последнюю неделю, магазины с выручкой выше плана, заказы без доставки. В NumPy это делают индексами, срезами и булевыми масками — без единого цикла.

Маски — главная идея уровня: сравнение `amounts > 1000` даёт массив `True`/`False`, и этим массивом можно отфильтровать данные. В pandas фильтрация таблиц работает точно так же, поэтому всё из этого уровня пригодится в P2. Босс — очистка показаний датчиков склада.

## Индексы и срезы {#indexing}

Индексы и срезы одномерного массива работают как у списков: счёт с нуля, отрицательные индексы — с конца, `start:stop:step` не включает `stop`.

```python run
import numpy as np

sales = np.array([120, 340, 90, 410, 260, 180, 300])
print(sales[0], sales[-1])
print(sales[2:5], sales[-3:], sales[::2])
```

Главное отличие от списков — срез массива это **представление** (view), а не копия: изменение среза меняет исходный массив. Если нужна независимая копия, вызывают `.copy()`.

```python run
import numpy as np

a = np.arange(6)
part = a[1:4]
part[0] = 100
print(a)
safe = a[1:4].copy()
safe[0] = -1
print(a)
```

## Двумерные массивы {#slicing2d}

В двумерном массиве индекс пишут через запятую: `m[строка, столбец]`. Срез по каждой оси задаётся отдельно, а двоеточие без чисел означает «все».

```python run
import numpy as np

m = np.array([[10, 11, 12, 13],
              [20, 21, 22, 23],
              [30, 31, 32, 33]])
print(m[1, 2], m[-1, -1])
print(m[0])
print(m[:, 1])
print(m[1:, :2])
```

`m[0]` — первая строка, `m[:, 1]` — второй столбец, `m[1:, :2]` — блок со второй строки и первые два столбца. Запись `m[1][2]` тоже работает, но `m[1, 2]` короче и быстрее.

Список индексов выбирает несколько элементов сразу: `a[[0, 3, 5]]` или `m[:, [0, 2]]`. Такая выборка, в отличие от среза, создаёт копию.

## Булевы маски {#masks}

Сравнение массива с числом даёт массив `True`/`False` той же формы — маску. Массив, проиндексированный маской, оставляет только элементы, где стоит `True`.

```python run
import numpy as np

amounts = np.array([450, 1290, 99, 3100, 990])
mask = amounts > 500
print(mask)
print(amounts[mask], amounts[amounts < 100])
print(mask.sum(), mask.mean())
```

`mask.sum()` считает `True` — сколько элементов прошло условие, а `mask.mean()` даёт их долю.

Условия объединяют операторами `&` (и), `|` (или), `~` (не), а каждое сравнение берут в скобки. Слова `and` и `or` с массивами не работают.

```python run
import numpy as np

amounts = np.array([450, 1290, 99, 3100, 990])
print(amounts[(amounts > 100) & (amounts < 1000)])
print(amounts[(amounts < 100) | (amounts > 3000)])
print(amounts[~(amounts > 1000)])
```

## where и поиск {#where}

`np.where(условие, a, b)` собирает новый массив: где условие истинно — берёт из `a`, иначе из `b`. С одним аргументом `np.where(условие)` возвращает индексы `True`.

```python run
import numpy as np

t = np.array([3.5, -999.0, 4.1, 5.0, -999.0])
print(np.where(t < -100, np.nan, t))
print(np.where(t < -100)[0])
print(np.clip(np.array([-5, 50, 150]), 0, 100))
```

`np.clip(a, lo, hi)` обрезает значения по границам. `argmax` и `argmin` дают индекс максимума и минимума, а `np.argsort` — индексы, которые отсортировали бы массив.

```python run
import numpy as np

rev = np.array([2.5, 9.1, 4.0, 7.7])
print(rev.argmax(), np.argsort(rev))
print(np.argsort(-rev)[:2], rev[np.argsort(-rev)[:2]])
```

## Частые ошибки {#mistakes}

and вместо &:

```python wrong
a[a > 1 and a < 5]
```

```python right
a[(a > 1) & (a < 5)]
```

Нет скобок вокруг сравнений:

```python wrong
a[a > 1 & a < 5]
```

```python right
a[(a > 1) & (a < 5)]
```

Изменение среза меняет оригинал:

```python wrong
top = prices[:3]
top[0] = 0
```

```python right
top = prices[:3].copy()
top[0] = 0
```

Индекс двумерного массива для одномерного:

```python wrong
a = np.array([1, 2, 3])
a[0, 1]
```

```python right
m = np.array([[1, 2, 3]])
m[0, 1]
```

## Шпаргалка {#cheatsheet}

```python
a[0]  a[-1]  a[2:5]  a[::2]  a[::-1]
a[[0, 3]]                 # выбор по списку индексов
m[1, 2]  m[0]  m[:, 1]  m[1:, :2]
a[1:3].copy()             # копия вместо представления
a[a > 5]  (a > 5).sum()  (a > 5).mean()
a[(a > 1) & (a < 5)]  a[(a < 1) | (a > 9)]  a[~mask]
np.where(cond, x, y)  np.where(cond)[0]
np.clip(a, 0, 100)
a.argmax()  a.argmin()  np.argsort(-a)[:3]
```
