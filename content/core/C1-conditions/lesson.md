# Условия

## Зачем это нужно {#why}

Программа редко делает одно и то же для любых данных. Скидка зависит от суммы заказа, статус клиента — от числа покупок, а доставка — от веса и расстояния. Условия позволяют программе выбирать, что делать.

В этом уровне ты научишься сравнивать значения, строить ветвления `if` / `elif` / `else` и объединять условия через `and`, `or`, `not`. В конце — босс: расчёт стоимости доставки ShopData по нескольким правилам.

## Сравнения и bool {#bool}

Операторы сравнения: `==` (равно), `!=` (не равно), `<`, `>`, `<=`, `>=`. Результат сравнения — значение типа `bool`: `True` или `False`.

```python run
x = 7
print(x > 5, x == 10, x != 3)
print(type(x > 5))
```

Сравнивать можно и строки: они сравниваются по алфавиту, посимвольно. Python разрешает цепочки сравнений, как в математике: `0 <= x < 10`.

```python run
print("apple" < "banana", "Яблоко" == "яблоко")
age = 25
print(18 <= age < 65)
```

Одиночный знак `=` — это присваивание, а не сравнение. В условии всегда пиши `==`.

## if и else {#if-else}

`if` выполняет блок, только если условие истинно. Блок — строки с отступом в 4 пробела после строки с двоеточием. `else` срабатывает, когда условие ложно.

```python run stdin="1500"
total = int(input())
if total >= 1000:
    print("Доставка бесплатная")
else:
    print("Доставка 299 руб.")
print("Спасибо за заказ")
```

Последняя строка без отступа выполняется всегда: она уже не входит в блок. Отступы определяют структуру программы, поэтому их нельзя ставить «на глаз».

Чётность проверяют остатком: `n % 2 == 0` — число чётное.

```python run stdin="7"
n = int(input())
if n % 2 == 0:
    print("чётное")
else:
    print("нечётное")
```

## Цепочка elif {#elif}

Когда вариантов больше двух, используют `elif` («иначе если»). Python проверяет условия сверху вниз и выполняет **первую** подходящую ветку, остальные пропускает.

```python run stdin="73"
score = int(input())
if score >= 90:
    print("отлично")
elif score >= 75:
    print("хорошо")
elif score >= 50:
    print("удовлетворительно")
else:
    print("неудовлетворительно")
```

Поэтому порядок важен. Если сначала проверить `score >= 50`, то 95 баллов попадут в «удовлетворительно»: до более строгого условия дело не дойдёт. Ставь сначала самые узкие условия.

## and, or, not {#logic}

Условия объединяются логическими операторами. `and` истинно, когда истинны обе части. `or` — когда истинна хотя бы одна. `not` меняет значение на противоположное.

```python run stdin="2024"
year = int(input())
leap = (year % 4 == 0 and year % 100 != 0) or year % 400 == 0
print(leap)
print(not leap)
```

Скобки делают порядок явным: `and` выполняется раньше `or`, но читать проще со скобками.

Python не считает вторую часть, если ответ уже ясен: в `False and ...` правая часть не вычисляется. Этим пользуются, чтобы избежать ошибки:

```python run
d = 0
print(d != 0 and 10 / d > 1)
```

## Вложенные условия {#nested}

Внутри блока `if` может быть ещё один `if` — со своим отступом. Так проверяют условие, которое имеет смысл только при выполнении внешнего.

```python run stdin="3 -2"
x, y = map(int, input().split())
if x > 0:
    if y > 0:
        print(1)
    else:
        print(4)
else:
    print("левая полуплоскость")
```

Глубокая вложенность читается тяжело. Часто её заменяет одно условие с `and`: `if x > 0 and y > 0:`. Выбирай вариант, где логика видна сразу.

Вложенный `if` удобен, когда во внешней ветке есть общие действия, которые нужны до внутренней проверки.

## Частые ошибки {#mistakes}

Присваивание вместо сравнения:

```python wrong
if x = 5:
    print("пять")
```

```python right
if x == 5:
    print("пять")
```

Широкое условие стоит первым, и узкое никогда не срабатывает:

```python wrong
if total >= 1000:
    discount = 5
elif total >= 5000:
    discount = 10
```

```python right
if total >= 5000:
    discount = 10
elif total >= 1000:
    discount = 5
```

`or` со значением вместо сравнения — условие всегда истинно:

```python wrong
if answer == "да" or "yes":
    print("ok")
```

```python right
if answer == "да" or answer == "yes":
    print("ok")
```

Переменная задана только в одной ветке:

```python wrong
if n > 0:
    sign = "плюс"
print(sign)
```

```python right
sign = "не плюс"
if n > 0:
    sign = "плюс"
print(sign)
```

`is` вместо `==` для чисел и строк:

```python wrong
if n is 10:
    print("десять")
```

```python right
if n == 10:
    print("десять")
```

## Шпаргалка {#cheatsheet}

```python
x == y   x != y   x < y   x >= y   0 <= x < 10
a and b    a or b    not a
if cond:
    ...
elif other:
    ...
else:
    ...
n % 2 == 0          # чётное
x % 3 == 0          # делится на 3
leap = (y % 4 == 0 and y % 100 != 0) or y % 400 == 0
```
