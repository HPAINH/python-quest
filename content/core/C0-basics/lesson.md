# Переменные, ввод и вывод

## Зачем это нужно {#why}

Любая программа аналитика делает три вещи: получает данные, считает и показывает результат. В этом уровне ты научишься всем трём: читать числа через `input()`, считать с помощью арифметики и печатать ответ через `print()`.

Пример из работы: дано число секунд в сессии пользователя, нужно показать его в формате `ч:мм:сс`. К концу уровня ты решишь эту задачу сам.

Каждый пример в уроке можно менять и запускать кнопкой «▶ Запустить». Меняй числа, ломай код и смотри, что получится.

## Переменные {#variables}

Переменная — это имя, к которому привязано значение. Значение задаётся знаком `=`: слева имя, справа значение. Потом имя можно использовать вместо значения.

```python run
price = 250
count = 3
total = price * count
print(total)
```

Переменную можно перезаписать: старое значение заменится новым. Справа от `=` может стоять та же переменная — сначала считается правая часть, потом результат записывается в имя.

```python run
balance = 1000
balance = balance - 300
balance += 50
print(balance)
```

Имена пишутся латиницей, цифрами и `_`, не начинаются с цифры, регистр важен: `total` и `Total` — разные переменные. Давай понятные имена: `revenue`, а не `r`.

## Типы данных {#types}

У каждого значения есть тип. Основные: `int` — целое число, `float` — дробное, `str` — строка в кавычках, `bool` — `True` или `False`. Узнать тип помогает `type()`.

```python run
print(type(42), type(3.5), type("42"), type(True))
```

Тип определяет, что делают операции. Числа складываются, а строки склеиваются. Поэтому `"2" + "3"` — это `"23"`.

```python run
print(2 + 3)
print("2" + "3")
print("ab" * 3)
```

Типы переводятся друг в друга функциями `int()`, `float()` и `str()`. Строку с числом нельзя сложить с числом напрямую — сначала переведи её.

```python run
age = "21"
print(int(age) + 1)
print("Мне " + str(22) + " года")
```

## Вывод: print {#print}

`print()` выводит значения через пробел и в конце переводит строку. Разделитель меняет параметр `sep`, окончание строки — `end`.

```python run
print("Python", "Quest")
print(2026, 10, 17, sep="-")
print("без переноса", end="")
print("!")
```

Удобнее всего собирать текст f-строкой: перед кавычкой ставится `f`, а значения подставляются в фигурных скобках. Внутри скобок можно писать выражения и задавать формат.

```python run
name = "Аня"
score = 87.456
print(f"{name}: {score:.1f} баллов, это {score / 100:.0%}")
print(f"{7:02d}:{5:02d}")
```

Формат `:02d` дополняет целое число нулём слева до двух знаков — так печатают время.

Каждый `print` — новая строка вывода. В задачах вывод сверяется с ответом посимвольно, поэтому лишние слова и пробелы считаются ошибкой.

## Ввод: input {#input}

`input()` читает одну строку ввода и **всегда возвращает строку**. Чтобы считать с числом, оберни ввод в `int()` или `float()`.

```python run stdin="7\n3"
a = int(input())
b = int(input())
print(a + b)
```

Если несколько чисел даны в одной строке через пробел, строку делят методом `split()`, а `map(int, ...)` переводит каждую часть в число.

```python run stdin="7 3"
a, b = map(int, input().split())
print(a * b)
```

Не пиши текст внутри `input("Введите число")` — он попадёт в вывод, и проверка не пройдёт. Каждый вызов `input()` читает следующую строку, поэтому число вызовов должно совпадать с числом строк ввода.

## Арифметика {#arithmetic}

Операторы: `+`, `-`, `*`, `/` (деление, всегда дробь), `//` (целая часть), `%` (остаток), `**` (степень). Порядок как в математике, скобки меняют его.

```python run
print(17 / 5, 17 // 5, 17 % 5, 2 ** 10)
```

`//` и `%` — главные инструменты для цифр числа: `n % 10` даёт последнюю цифру, `n // 10` отбрасывает её.

```python run
n = 4721
print(n % 10, n // 10 % 10, n // 100 % 10, n // 1000)
```

Для времени: `сек // 60` — минуты, `сек % 60` — остаток секунд. `round(x, 2)` округляет, а `abs(x)` даёт модуль числа.

```python run
seconds = 3725
print(seconds // 3600, seconds % 3600 // 60, seconds % 60)
print(round(2 / 3, 2), abs(-5))
```

## Частые ошибки {#mistakes}

Ввод без перевода в число складывает строки:

```python wrong
a = input()
b = input()
print(a + b)
```

```python right
a = int(input())
b = int(input())
print(a + b)
```

Несколько чисел в одной строке нельзя перевести одним `int()`:

```python wrong
a, b = int(input())
```

```python right
a, b = map(int, input().split())
```

Текст внутри `input()` попадает в вывод:

```python wrong
n = int(input("Введите n: "))
```

```python right
n = int(input())
```

Деление `/` даёт дробь, даже если делится нацело:

```python wrong
print(10 / 2)
```

```python right
print(10 // 2)
```

Незакрытая скобка — частая синтаксическая ошибка:

```python wrong
print(int(input())
```

```python right
print(int(input()))
```

## Шпаргалка {#cheatsheet}

```python
x = 5                          # переменная
n = int(input())               # одно целое число
a, b = map(int, input().split())  # два числа в строке
s = input()                    # строка как есть
print(a, b, sep=", ", end="!\n")
print(f"{x:.2f}")              # 2 знака после запятой
17 // 5   # 3   целая часть
17 % 5    # 2   остаток
2 ** 10   # 1024
round(3.14159, 2)  # 3.14
int("12"), float("2.5"), str(10)
```
